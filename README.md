# NPB Stats Lab

プロ野球(NPB)公式サイトの成績データをもとにしたセイバーメトリクス分析・順位予想サイト。

## 使い方

初回のみ仮想環境をセットアップ:

```powershell
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
```

サイトを生成:

```powershell
.\.venv\Scripts\python.exe build_site.py 2026   # 引数省略時は2026年度
```

`site/index.html` をブラウザで開けば閲覧できる。サーバー不要(静的HTML)。

データは初回取得時に `data/raw/` にキャッシュされ、2回目以降は再取得しない。
最新の試合結果を反映したい場合は `data/raw/` を削除してから再実行する。

規定打席・規定投球回未満の選手も含めて全選手ページを生成するため、初回ビルドは
各球団の選手名鑑(12球団分)と対象選手の個人ページを1件ずつ取得する関係で
数分〜十数分かかる(npb.jpへの配慮のため1秒間隔でアクセス)。2回目以降はキャッシュ
により数秒〜数十秒で終わる。予告先発・試合日程・選手個別ページの一部は
シーズン進行に応じて内容が変わるため、これらはキャッシュせず毎回取得する。

## 構成

- `npb_data/scraper.py` — npb.jp公式サイトから打撃・投手・チーム成績・順位表を取得
- `npb_data/sabermetrics.py` — OPS, ISO, wOBA, RC27, BABIP, WHIP, FIP等を算出
- `npb_data/predictions.py` — ピタゴラス勝率によるモンテカルロ順位シミュレーション、log5法、残りシーズン成績予想
- `build_site.py` — 上記を組み合わせて `site/` に静的HTMLを出力
- `templates/`, `static/` — サイトのHTML/CSS

## 対応済み指標

打者: OPS, ISO, wOBA(簡易), RC, RC27, BABIP, K%, BB%, wRC+(簡易), WAR(簡易・打者のみ)
投手: WHIP, FIP, K/9, BB/9, K/BB, K%, BB%
チーム: ピタゴラス勝率, 得失点差, 「運」(実勝利-期待勝利)

### WAR(簡易版)について

[baseballhub.app](https://baseballhub.app/methodology) の簡易算出法を採用した近似値。
OPSから概算したwRC+・出場試合数・盗塁数・守備位置補正のみで計算し、UZR等の詳細な
守備データは使わない。守備位置は選手名鑑の「捕手/内野手/外野手/投手」区分しか
使えないため、内野手は一律+0.30補正(一塁手をやや過大評価)。DHは名鑑上の守備位置と
区別できないため未対応。投手WARは参照元でも未提供のため本サイトでも対象外。

## 対象外の指標

UZR, DRS, wSB, UBR, パークファクター、投手WAR — 打球追跡データ・詳細な守備データが
必要で、NPB公式サイトの基本成績ページからは取得できないため未実装。

## インターネットへの公開 (GitHub Pages)

`.github/workflows/build-and-deploy.yml` により、GitHub Actionsが毎日16:00 UTC(01:00 JST、
その日の全試合が確実に終わっている時刻)に自動でデータ取得・サイト生成・GitHub Pagesへの
デプロイまで行う。PCの電源状態に依存せずクラウド側で完結する。

セットアップ手順(初回のみ):
1. GitHubでリポジトリを作成し、このフォルダの中身をpush
2. リポジトリの Settings → Pages → Source を「GitHub Actions」に設定
3. Actions タブで `Build and deploy NPB Stats Lab` を一度手動実行(workflow_dispatch)して動作確認

ローカルの `daily_update.py` + タスクスケジューラは、GitHub Pagesで公開する場合は不要になる
(ローカルで `site/` を見るだけなら引き続き使える)。

## 規定打席・規定投球回未満の選手

各球団の選手名鑑(支配下選手)を取得し、規定打席・規定投球回に達していない選手についても
個人ページ(打撃・投手成績、残りシーズン予想)を生成する。チームページの「その他の選手」
セクション、および打撃・投手成績一覧からリンクされる。

## 直近10試合の好調・不調選手

各チームの直近10試合のボックススコア(個人成績)を集計し、シーズン成績と比べて調子が
上がっている・落ちている選手を抽出する(`trend.html`)。打者は打率の推移、投手は防御率の
推移で判定。ボックススコアは試合終了後は内容が変わらないためキャッシュし、日々の差分
(新しく終了した試合)のみ追加取得する。

## 選手の顔写真・チームロゴ

選手個人ページ・チームページに、npb.jp公式の選手写真/球団ロゴを表示する。マスコット
キャラクターの画像はnpb.jp上に見つからなかったため、代わりに球団ロゴを使用している。

## 予想手法について

- **順位予想**: 各チームのピタゴラス勝率を「勝つ力」として残り試合をモンテカルロ・シミュレーション(2万回試行)
- **勝敗予想**: log5法(Bill James考案)で2チームの勝率から対戦時の勝率を推定
- **選手成績予想**: 現在の打撃3率を「安定化点」(サンプルサイズに応じてリーグ平均へ回帰させる統計的しきい値)で補正し、現在の出場ペースで残り試合を延伸。今シーズン終了時点の着地予想であり、来シーズン予測ではない

いずれも機械学習モデルではなく、少ないデータでも機能する古典的なサイバーメトリクス手法。
